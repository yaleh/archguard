## Finding

`TestCoverageRenderer.nodeId()` generates Mermaid node IDs from entity labels. Entity
labels that differ only in non-alphanumeric characters or truncation produce identical
node IDs, causing Mermaid to silently drop entities from diagrams. This affects quay's
visual architecture output — entities can be missing from coverage and dependency diagrams
without any error signal.

## Acceptance Criteria

- [x] Entity labels differing only in non-alphanumeric characters produce distinct node IDs
- [x] Truncated labels that collide produce distinct node IDs
- [x] Existing diagram output verified — no previously-dropped entities now missing from new output
- [x] Test added: two entities with colliding labels → both appear in diagram output

## Definition of Done

- [ ] nodeId() collision fixed
- [ ] Collision detection test added (RED→GREEN)
- [ ] Affected quay diagrams regenerated and verified complete

## Proposal

Migrate all 28 files (27 unique TASK-IDs) from `backlog/tasks/*.md` into the quay-native provider (`./quay-tasks/`) so the quay loop-driver and MCP tools become the single source of truth for the archguard task board. TASK-24 and TASK-25 were already seeded manually during DIR-036-B bootstrap; those files must not be duplicated. The duplicate `task-1` pair (two files sharing `id: TASK-1`, different titles) must each be preserved — the GoPlugin refactor keeps `TASK-1`, the QueryEngine refactor is assigned `TASK-28` (next available slot) during migration.

Approach: for each `backlog/tasks/task-N - *.md` file, parse YAML frontmatter, map status (see Requested action), carry body verbatim, append `source:backlog-TASK-N` label, and create a `quay-tasks/TASK-N.md` file. Skip TASK-24 and TASK-25 (already present).

## Plan

## Finding

`backlog/tasks/` holds 28 files (27 unique TASK-IDs: TASK-1 through TASK-27, with TASK-1 having two distinct files with different titles). The quay-native store (`quay-tasks/`) contains only TASK-24 and TASK-25, seeded as proof-of-concept during DIR-036-B plumbing. ## Requested action

1. For each `backlog/tasks/task-N - *.md` (N = 1…27, 28 files), read YAML frontmatter and body.
2. Map backlog status → quay status:
   - `Done` / `Basic: Done` / `Epic: Done` → `done`
   - `Basic: Ready` / `Epic: Ready` → `ready`
   - `Basic: In Progress` / `Epic: In Progress` → `todo`
   - `Basic: Proposal` / `Basic: Plan` / `Basic: Backlog` / `Epic: *` → `todo`
   - `Basic: Needs Human` / `Epic: Needs Human` → `needs-human`
3. Skip TASK-24 and TASK-25 (already in quay-tasks).
4. Resolve the duplicate TASK-1:
   - File `task-1 - GoPlugin-God-Object-…` → `TASK-1` (keep original id)
   - File `task-1 - QueryEngine-God-Object-…` → `TASK-28` (next available id)
5. For each task, write `quay-tasks/TASK-N.md` with YAML frontmatter (id, title, status, labels including `source:backlog-TASK-N`, parent: null, children: []) and the original markdown body.
6. After all writes, verify count and spot-check TASK-5, TASK-15, TASK-27.

## Proposal

将项目 8 个 ADR（`docs/adr/001-*.md` … `008-*.md`）迁移至 quay-native ADR 存储（`quay-adr/`），以 quay-adr 为正本，`docs/adr/` 改为 stub 重定向文件，`docs/adr/README.md` Index 表更新指向新路径。

迁移步骤：
1. 创建 `quay-adr/` 目录。
2. 为每个 ADR 写 `quay-adr/ADR-NNN.md`：添加 YAML frontmatter（id、title、status 英文化、date、tags 推断自内容），正文内嵌元数据行（`**状态**: 已采纳` 等）保留不动。
3. 将 `docs/adr/001-*.md` … `008-*.md` 替换为单行 stub（`> This ADR has moved to [quay-adr/ADR-NNN.md](../../quay-adr/ADR-NNN.md)`）。
4. 更新 `docs/adr/README.md` Index 表链接指向 `../../quay-adr/ADR-NNN.md`。
5. git commit。

理由：quay ADR 工具（`adr_list`、`adr_write`）和 loop-driver 需要单源才能枚举完整 ADR 列表；双源（additive 方案 A）会导致工具只能看到 quay-adr 而正文更新在 docs/adr，形成永久漂移。

## Plan

N/A — directive resolved via a one-shot migration; no staged plan document.
